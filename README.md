# Bushido Table Tracker

A phone and tablet app for tracking games of Bushido: turn phases, wounds, Ki, states,
Ki feats, card reminders, an opponent strip, saved warbands and saved games.

**Open the app:** https://floateruk.github.io/bushido/
(In Chrome: ⋮ → Add to Home screen → Install.)

- **Import lists** from newrecruit.eu PDF exports: stats, Ki feats, equipment, card text and the rules glossary.
- **Works offline** once opened online. PDFs can be imported offline too.
- **Syncs between devices** through Firebase when they share a sync code (Sync button at the bottom).

Your games are never stored in this repository. They live on each device and in your Firebase project.
